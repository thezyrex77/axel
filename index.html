Cara Bayar Menggunakan QRIS

QRIS (Quick Response Code Indonesian Standard) menyatukan berbagai macam QR code dari berbagai aplikasi pembayaran digital seperti BCA, Mandiri, BRI, BNI, GoPay, OVO, DANA, dan LinkAja.

1
Pilih Paket & Isi Form Order

Tentukan paket pilihan Anda di bawah dan lengkapi data pemesanan.

2
Scan QRIS di Bawah Ini

Buka aplikasi m-Banking atau E-Wallet Anda, lalu scan QR Code QRIS resmi kami.

3
Kirim Bukti via WhatsApp

Klik tombol kirim pesanan otomatis untuk mengirim detail & bukti transfer ke WhatsApp admin.
